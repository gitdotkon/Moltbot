# Moltbot Skills

This repository contains skill definitions for Moltbot, an AI agent system.

## Skills Overview

| Skill | Description |
|-------|-------------|
| [ppt-assistant](skills/ppt-assistant/) | Generate PPT presentations with content from GitHub, StackOverflow |
| [nano-pdf](skills/nano-pdf/) | Edit PDFs using natural language instructions |
| [github](skills/github/) | Interact with GitHub via gh CLI |
| [coding-agent](skills/coding-agent/) | Run Codex CLI, Claude Code, OpenCode for coding tasks |
| [social-trending](skills/social-trending/) | Fetch trending topics from Baidu, Weibo, BiliBili, Douyin |
| [price-compare](skills/price-compare/) | Compare prices across Chinese e-commerce platforms |
| [moltbook](skills/moltbook/) | Social network for AI agents |

## Usage

Each skill directory contains a `SKILL.md` file with detailed documentation on how to use the skill.

## Updating Skills

To update skills:
1. Modify the skill files in `/Users/kon/clawd/skills/` or `/Users/kon/clawd/moltbook-skill/`
2. Run the sync script or manually copy files to this repository
3. Commit and push changes
